# Controlled claim recall: aggregate result

## Completed scope

An isolated, minimal read-only tool-use loop evaluated eight fixed questions over nine frozen real memory items. There were sixteen fresh real-model trials on `openai-codex / gpt-6.1-sol`.

A received ordered exact routes only. B received the same routes plus existing authored navigation claims. Route coverage, original bodies, tool schema, instructions, question order and budgets were identical. Expected answers were never injected into model inputs.

The executable experiment, original corpus, raw provider/tool evidence, manifests and per-trial semantic reviews are retained **privately**, not distributed as public product fixtures. This document intentionally contains aggregate results only.

## Corrected whole run

- 16/16 trials completed; eight complete matched pairs.
- No provider errors or budget-censored outcomes.
- A: 54 successful memory opens, 62 model responses, 85,403 provider-reported total tokens.
- B: 10 successful memory opens, 18 model responses, 21,733 provider-reported total tokens.
- Both conditions reached expected evidence in all seven questions with predeclared supported routes. One additional question intentionally lacked supporting evidence.
- Independent trace review verified all 64 returned originals, 64 public-output/tool-result continuations, 16 terminal answers and the claims-only paired intervention.

The 5.4-fold opening-count difference is descriptive, not a runtime-speed or general efficacy guarantee. These conditions use opaque item routes; they are not a native-host comparison or a comparison with another semantic map.

## Independent semantic review

- A: six fully supported answers and two partially supported answers.
- B: eight fully supported answers.
- No wholly unsupported final answer; every trial performed actual retrieval.

The two partial answers correctly recovered the principal policy/route content but added unsupported historical linkage: a particular predecessor/supersession chronology, and an identification of a current retrieval address with a historical smoke-test address. Consolidation dates and successful current retrieval do not independently establish those historical relationships.

For the missing-evidence probe, one condition opened all nine bodies and the other opened two relevant candidates. A defensible negative answer is bounded absence of confirmation in opened evidence, not proof of universal nonoccurrence or an exhaustive search that did not happen.

## Transport correction and preserved history

The first whole run had twelve completed answers and four HTTP 400 interruptions caused by replaying SDK response-only `reasoning.status` as request input. That run was preserved unchanged and reviewed separately: eleven supported, one partially supported and four transport-censored outcomes.

The narrow correction projects actual public outputs into legal request inputs, preserves literal call IDs/names/arguments and ordered text, and excludes opaque reasoning and response-only metadata. Strict RED regressions reproduced the captured failures. The corrected run repeated the complete paired scope rather than selectively replacing failed arms. The two runs are not pooled into an apparent larger efficacy sample.

The private experimental artifact passed 424 Python tests (89 focused) plus 14 standalone Node tests. Independent spec and quality/security reviews covered the initial harness and transport correction. Product source, host adapters and live memory were not changed by this experiment; the product baseline had 335 passing Python tests.

## Next bounded slice

Claims proved useful as cheap entrances in this selected test; they did not make route-only recall impossible. The unsupported additions identify a different need: preserve authored relationship meaning and uncertainty rather than rediscover predecessor/supersession topology from timestamps or thematic similarity.

The next planned slice remains optional exact-route `continues / corrects / follows_from` relations, a controlled linked-arc reconstruction and one deliberate consolidation experiment. No relation mechanism, forgetting, automatic graph-to-engram promotion or Pulse/Grow implementation was included in this slice.

## Publication boundary

The real-memory experiment was initially pushed to a public feature branch before repository visibility was checked. That was a publication-boundary mistake. Its complete working artifact has since been preserved in an explicitly private repository, and the newly created public experiment branch was removed. Public product main was not rewritten.

Prior secret scans found no real credentials in those traces, but semantic memory is not automatically public test data. Branch removal does not guarantee erasure of earlier commits: objects may remain reachable by hash, caches or clones. Future public harness distribution should use explicit inputs and neutral reproducible fixtures, not original conversation traces.
