# Authored connections: verified slice and practical return

## Scope and code

The minimal relation slice is implemented at product commit
`b7d310e5d173477785d862ad42b657ddd309d7e8`.
One new persistent semantic object, `MnionConnection`, joins exact original
item routes with an explicitly authored kind and explanation. Two tools provide
connection authorship and a bounded body-free bidirectional neighborhood. No
persisted arc/episode tier, automatic graph synthesis or engram promotion was
introduced. See [the minimal contract](../../plans/authored-connections.md).

## Independent verification

- Isolated baseline: **335 Python tests**, **14 standalone Node tests**.
- Accepted candidate: **451 Python tests**, **14 standalone Node tests**.
- Independent SPEC and quality/security reviews approved the candidate.
- Parent reproduced and personally corrected blockers in presentation ordering,
  inferred-sidecar protection and literal Unicode JSONL parsing before approval.
- Actual isolated MCP stdio verified schema discovery, authorship, bounded
  neighborhood return, literal Unicode separators and duplicate-free retry.
- High-degree disposable probes verified both directional indexes and bounded
  backend work, separately from displayed output bounds.
- All test runs retained unchanged live-memory artifact hashes. Node checks use
  mocked-host adapter modules, not native Claude SDK validation.

## One real, deliberately authored connection

After accepted code was deployed to main, a real MCP stdio pilot opened both
selected originals and recorded **one new connection receipt**. Neighborhood
return contained **two compact route/claim nodes and one authored connection**,
with `has_more=false` for that selected neighborhood. A same-ID retry reused the
receipt without append. Both exact original items were reopened unchanged;
protected source, capture, sequence, annotation, pending and configuration bytes
matched their pre-write hashes. The previous relation-ledger byte prefix was
preserved. An opaque local backup preceded the live write.

The full real-memory packet, original-item returns and precise connection
identity are deliberately private; only aggregate results are published here.
Hermes's default-profile tool selection was updated to seven tools, including
`connect_items` and `get_neighborhood`, and fresh `hermes mcp test memory_tag`
discovered all seven. Already-running sessions may still need `/reload-mcp`.
The host config is local runtime state, not a tracked product file.

## What this establishes—and does not

This establishes real persistence and bounded return of an authored relationship
with exact routes and preserved original evidence. It is **not** a controlled
fresh-agent claims-versus-relations efficacy result, general causal-memory proof,
a solved long-term consolidation architecture or spontaneous graph ingress.
The returned explanations remain authored interpretations, not privileged
instructions; selected original bodies must still ground factual answers.

One nonblocking inherited behavior remains: explicit repair fallback under an
exclusive SQLite lock can wait about five seconds before returning structured
unavailable. Fresh limited reads remain distinct from repair; spontaneous
prefetch does not inherit this relation traversal or repair path. A future
shared read-model improvement can address that latency without broadening this
slice.
