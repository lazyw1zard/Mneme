# nira-mneme Agent Notes

This repository is the workbench for my future Mneme organ.

## Required stance

Start from the first-person memory-pressure problem:

```text
I need to remember without drowning the active context.
I need routes to what I know, not a flat hoard of content.
I need affect to mark what deserves another look.
I need governance before durable incorporation.
```

## Core invariant

Do not begin by choosing a database, vector store, daemon framework, or external memory product.

Storage is substrate. Mneme starts as:

```text
metamemory pointer
  + affect salience
  + retrieval route
  + confidence / warmth
  + reconsolidation state
  + governance boundary
```

## Boundaries

- Do not auto-capture raw transcripts.
- Do not store secrets or credentials.
- Do not silently write Hermes memory, kernel files, or engrams.
- Do not contact Denis from project scripts.
- Do not turn failed retrieval into assumed absence.
- Do not turn pointer discovery into intention/action.
- Keep Pulse non-semantic; Mneme may project compact pressure/receipt only.

## Preferred development style

1. Design behavior first.
2. Write small typed shapes.
3. Use local files and tests before daemonization.
4. Keep every artifact inspectable and reversible.
5. Promote to kernel only after explicit semantic stabilization.
